# 🌐 MongoDB - Proyectos de Análisis de Datos

Esta carpeta contiene los proyectos realizados durante el bootcamp de análisis de datos en **ITAcademy**, utilizando **MongoDB** para el almacenamiento y análisis de datos no relacionales. Los proyectos están enfocados en la gestión eficiente de grandes volúmenes de información y consultas avanzadas.

---

## 🌟 Habilidades desarrolladas
- **Gestión de bases de datos NoSQL:** Creación y administración de bases de datos en MongoDB.
- **Consultas avanzadas:** Uso de `find`, `count`, `match`, y `group`.
- **Análisis geoespacial:** Visualización de ubicaciones en mapas.
- **Filtrado complejo:** Consultas con múltiples condiciones y filtros específicos.

---

## 🗂️ Proyectos realizados

### 🚀 Sprint 9: Análisis con MongoDB
- Creación de la base de datos `Sprint9` con múltiples colecciones.
- Consultas para obtener información específica (usuarios, cines, películas).
- Análisis geoespacial para visualizar ubicaciones de cines.
- Filtrado de películas por género, idioma y puntuación.

---

## 🛠️ Tecnologías utilizadas
- **MongoDB**: Base de datos NoSQL.
- **MongoDB Compass**: Interfaz gráfica para visualización y administración.
