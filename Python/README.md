# 🐍 Python - Proyectos de Análisis de Datos

Esta carpeta contiene los proyectos y tareas realizados durante el bootcamp de análisis de datos en **ITAcademy**, utilizando **Python** para el análisis, procesamiento y visualización de datos. Los proyectos están enfocados en la manipulación de grandes volúmenes de información, análisis estadístico y visualización de resultados de manera clara y eficiente.

---

## 🌟 Habilidades desarrolladas
- **Análisis de datos con Pandas:** Limpieza, transformación y manipulación de grandes volúmenes de información.
- **Visualización avanzada de datos:** Uso de **Matplotlib** y **Seaborn** para crear gráficos personalizados.
- **Análisis estadístico:** Exploración de patrones, correlaciones y tendencias en los datos.
- **Integración con Power BI:** Uso de scripts de Python para enriquecer visualizaciones en dashboards interactivos.
- **Uso de Jupyter Notebooks:** Desarrollo de scripts y visualizaciones documentadas y reproducibles.

---

## 🗂️ Proyectos realizados

### 🚀 Sprint 7: Análisis de Datos con Python
- Análisis de datos transaccionales utilizando Pandas.
- Creación de visualizaciones estadísticas con Matplotlib y Seaborn.
- Exploración de patrones de compra y tendencias en los datos.
- Generación de gráficos para la interpretación visual de los resultados.

---

### 📊 Sprint 8: Integración de Python en Power BI
- Generación de gráficos personalizados utilizando **Python** dentro de Power BI.
- Creación de scripts para visualizar datos con **Seaborn** y **Matplotlib**.
- Integración de gráficos Python en informes interactivos de Power BI.
- Documentación clara de cada script y visualización.

---

## 🛠️ Tecnologías utilizadas
- **Python**: Análisis y visualización de datos.
  - **Pandas**: Limpieza y manipulación de datos.
  - **Matplotlib**: Gráficos personalizados.
  - **Seaborn**: Visualización estadística.
- **Jupyter Notebook**: Desarrollo de scripts de análisis.
- **Power BI**: Integración de visualizaciones avanzadas.
