# 📊 Power BI - Proyectos de Análisis de Datos

Esta carpeta contiene los proyectos y tareas realizados durante el bootcamp de análisis de datos en **ITAcademy**. Utilicé **Power BI** para crear dashboards interactivos que facilitan la interpretación de información empresarial, optimizando la toma de decisiones mediante gráficos intuitivos y visualizaciones de alto impacto.

---

## 🌟 Habilidades desarrolladas
- Visualización de datos efectiva y creación de dashboards interactivos.
- Análisis de ventas y transacciones a nivel nacional e internacional.
- Uso de **DAX** para cálculos avanzados y medidas personalizadas.
- Visualización geográfica para representar la distribución de ventas y clientes.
- Análisis comparativo de rendimiento entre años y usuarios.

---

## 🗂️ Proyectos realizados

### 🚀 Sprint 5: Visualización de Datos de Ventas
- Conexión de Power BI con bases de datos MySQL.
- KPIs para medir el rendimiento de ventas anuales.
- Gráficos para analizar ventas por país y patrones estacionales.
- Visualización de la distribución geográfica de ventas.

### 📊 Sprint 6: Análisis Avanzado de Ventas y Usuarios
- Dashboards comparativos entre 2021 y 2022.
- Análisis de usuarios destacados y rendimiento por país.
- Mapas interactivos para visualizar la distribución geográfica.

---

## 🛠️ Tecnologías utilizadas
- **Power BI**: Visualización de datos.
- **DAX**: Cálculos y medidas avanzadas.
- **SQL (MySQL)**: Consulta y manipulación de datos.
- **CSV**: Carga de datos en Power BI.
