# 💻 ITAcademy - Bootcamp de Análisis de Datos 📊

Este repositorio contiene todos los proyectos y tareas realizados durante el bootcamp de análisis de datos en **ITAcademy**. A lo largo del programa, adquirí habilidades fundamentales en análisis de datos, manipulación de datos, creación de visualizaciones efectivas y administración de bases de datos. Los proyectos están organizados según la herramienta utilizada y están basados principalmente en una base de datos ficticia llamada **Transacciones**, que simula los registros de transacciones, productos, clientes y otros datos de una empresa.

## Habilidades adquiridas

Durante el bootcamp, desarrollé competencias clave en el ámbito del análisis de datos, tales como:

-  📝 **Análisis de datos con SQL:** Creación de consultas complejas para obtener información de grandes conjuntos de datos, uso de funciones de agragación, uniones, subconsultas y optimización de consultas para un análisis eficiente.

- 📊**Visualización y presentación de datos con Power BI:** Diseño de dashboards interactivos que facilitan la comprensión de los resultados de los análisis, destacando patrones, tendencias y métricas clave.

- 🐍**Análisis y procesamiento de datos con Python:**
  - 🐼Uso de **Pandas** para limpiar, transformar y analizar datos de manera eficiente.
  - 📈Creación de gráficos descriptivos y exploratorios con **Matplotlib** y **Seaborn** para visualizar patrones y correlaciones.

- 🗃️**Manejo de bases de datos no relacionales con MongoDB:** Almacenamiento y consulta de datos en formato flexible, realizando búsquedas avanzadas y análisis de información no estructurada.

## 🛠️Tecnologías utilizadas

- **SQL (MySQL)**: Consultas, análisis de datos y generación de informes.
- **Power BI**: Visualización y creación de dashboards interactivos.
- **Python**:
  - **Pandas**: Análisis y manipulación de datos.
  - **Seaborn**: Visualización de datos.
  - **Matplotlib**: Gráficos y visualizaciones.
- **MongoDB**: Almacenamiento y consulta de datos no relacionales.
