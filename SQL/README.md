# 💾 SQL - Proyectos de Análisis de Datos

Esta carpeta contiene los proyectos y tareas realizados durante el bootcamp de análisis de datos en **ITAcademy**, enfocados en el manejo y análisis de datos utilizando **SQL**. Los proyectos están orientados al análisis de transacciones y compañías en un entorno empresarial ficticio.

---

## 🌟 Habilidades desarrolladas
- Diseño y creación de esquemas de bases de datos relacionales.
- Consultas avanzadas utilizando **JOIN**, **subconsultas**, **vistas** y **índices**.
- Optimización de consultas mediante el uso de índices y filtros específicos.
- Manejo de grandes volúmenes de datos para obtener métricas clave, como ventas promedio y transacciones exitosas.
- Análisis de datos estructurados, identificación de patrones de compra y optimización de recursos.

---

## 🗂️ Proyectos y tareas

### 🚀 **Sprint 2: Análisis de Transacciones con SQL**
- Exploración de datos de transacciones y compañías.
- Consultas avanzadas con **JOIN** y **subconsultas**.
- Identificación de empresas con ventas superiores a la media.
- Análisis de ingresos máximos por día y promedio de ventas por país.
- Eliminación de empresas sin transacciones registradas.

### 🧠 **Sprint 3: Gestión de Tarjetas de Crédito y Vistas**
- Creación de una tabla para almacenar datos de tarjetas de crédito.
- Modificación de registros con datos erróneos.
- Generación de vistas específicas para departamentos como marketing y recursos humanos.
- Filtrado de vistas por país y empresa.

### 🌟 **Sprint 4: Integración de Datos desde Archivos CSV**
- Diseño de una base de datos con **modelo estrella** para análisis multidimensional.
- Carga de datos desde archivos CSV, con normalización y transformación.
- Generación de tablas intermedias para conectar productos con transacciones.
- Análisis de ventas de productos y estado de tarjetas de crédito.

---

## 🛠️ **Tecnologías utilizadas**
- **MySQL**: Para la gestión y análisis de bases de datos relacionales.
